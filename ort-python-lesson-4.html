מהי לולאה?

לולאה היא קטע קוד שחוזר על עצמו. היא חוסכת שכפול, מקלה על תיקונים ומאפשרת להריץ פעולה גם מאות פעמים.

שני סוגים

while כל עוד תנאי מתקיים

for מעבר על רצף ידוע מראש

החלטה ראשונה טרם נבדק

צריך לבקש סיסמה שוב ושוב עד שהמשתמש מקליד את הסיסמה הנכונה. איזו לולאה מתאימה יותר?

לולאת while

נשתמש ב־while כשקוד צריך לרוץ כל עוד תנאי מתקיים, ולעיתים כשלא יודעים מראש כמה חזרות יהיו.

while עם מונה

i = 0
while i < 5:
    print(i)
    i += 1

בכל חזרה מדפיסים את i ואז מגדילים אותו ב־1.

while עם מספר אקראי

import random

n = 0
while n != 3:
    n = random.randint(0, 9)
    print(n)

randint מחזירה מספר אקראי בטווח כולל. לא יודעים כמה ניסיונות יידרשו עד שיתקבל 3.

חשוב: השורות ששייכות ללולאה מוזחות פנימה. ב־while חייב להיות שינוי שיכול להפוך את התנאי ל־False.

ניבוי לפני הרצה טרם נבדק

i = 1
while i < 5:
    print(i)
    i += 2

שילוב לולאות ותנאים

הלולאה עוברת על כל המספרים, והתנאי מחליט אילו מהם מתאימים.

for num in range(1, 11):
    if num % 2 == 0:
        print(num)
הסימן % מחזיר שארית. אם השארית בחלוקה ל־2 היא 0 — המספר זוגי.

break ו־continue

break — יציאה מלאה

for x in range(5):
    if x == 3:
        break
    print(x)

continue — דילוג אחד

for x in range(1, 5):
    if x == 3:
        continue
    print(x)

מה יודפס בדוגמת continue?

תרגול כיתה

נסו קודם לבד. הבדיקה נותנת משוב אבחוני; הרמז והפתרון נפתחים רק לפי בחירה.

תרגיל 1 · קלט עד עצירה טרם נבדק

קלטו ערכים כל עוד המשתמש לא הזין את הספרה 4. כשהוזנה 4 — עצרו.

צריך while שמשווה למחרוזת "4", ובתוך הלולאה צריך לקלוט ערך חדש.
value = input("הכניסו ערך: ")
while value != "4":
    value = input("נסו שוב: ")
print("עצירה")

תרגיל 2 · סינון מספרים טרם נבדק

הדפיסו את המספרים בין 1 ל־100 שהם אי־זוגיים וגם מתחלקים ב־3.

אי־זוגי: השארית בחלוקה ל־2 אינה 0. מתחלק ב־3: השארית בחלוקה ל־3 היא 0.
for num in range(1, 101):
    if num % 2 != 0 and num % 3 == 0:
        print(num)

שיעורי בית והעמקה

משימה 1 · משפט סודי

קלטו ערכים בלולאה עד שהמשתמש מזין print hello world. לאחר מכן הדפיסו hello world וסיימו.

משימה 2 · מספרים ראשוניים

הדפיסו את כל המספרים הראשוניים מ־1 עד 20. זכרו ש־1 אינו ראשוני. מומלץ להשתמש בלולאה בתוך לולאה.

העמקה · תכננו לולאה מקוננת טרם נבדק

כתבו שלד: לולאה חיצונית שעוברת על המועמדים 2–20 ולולאה פנימית שבודקת מחלקים.

התחילו בהנחה שהמספר ראשוני. בדקו מחלקים מ־2 עד number-1; אם נמצאה חלוקה ללא שארית, שנו את ההנחה ועצרו עם break.
for number in range(2, 21):
    is_prime = True
    for divisor in range(2, number):
        if number % divisor == 0:
            is_prime = False
            break
    if is_prime:
        print(number)

בונוס המערך · בלי if

הדפיסו את כל המספרים הזוגיים בין 1 ל־30 בסדר הפוך. חובה להשתמש ב־range, ללא תנאים.

# השלימו את שלושת ערכי range
for number in range(__, __, __):
    print(number)

בחרו נכון
