  2. 8–18 — הדגמה קצרה בלי פתרון מלא
    מדגימים רק התחלה: בלוק אחד או שניים שמראים סדר פעולות. לא חושפים את כל הפתרון.
  3. 18–34 — בנייה מודרכת
    מובילים את תרגילים 1–4 בקצב כיתה, עם עצירות ניבוי קצרות.
  4. 34–48 — בלוק → Python
    מחברים בין הבלוקים לשורות הקוד. מדגישים את הגשר: בלוק → שורת קוד מודגשת.
  5. 48–64 — תרגול עצמאי

  6. 64–76 — דיבאג ושיפור

  7. 76–84 — שדרוג יצירתי קצר

  8. 84–90 — שיתוף וסיכום

🧪 הרבה תרגולים לשיעור — 1–6

  1. תרגול 1 — חימום — מריצים ורואים: בנו מדרגה שיורדת ימינה: קטע ישר, ירידה קצרה, ואז המשך ישר.
    רמז: חשבו על צורת מדרגה: קודם קטע ישר, אחר כך ירידה קצרה, ואז ממשיכים ישר. אחרי כל שינוי הריצו ובדקו אם הציור נראה כמו מדרגה.
    בדיקה: יש מדרגה שיורדת ימינה: התחלה ישרה, ירידה קצרה, ואז המשך ישר.
  2. תרגול 2 — רצף מדרגות: בנו רצף של 3 מדרגות יורדות, בלי להשתמש בבלוק חזור.
    רמז: בכל מדרגה צריך לראות קטע ישר, ירידה קצרה, ואז עוד קטע ישר אחרי הירידה.
    בדיקה: יש רצף של 3 מדרגות יורדות, בלי בלוק חזור.
  3. תרגול 3 — שינוי קטן ובטוח: בקוד שבניתם בתרגיל הקודם, שנו רק כיוון של פנייה אחת: מימינה לשמאלה או משמאלה לימינה.
    רמז: אל תשנו את המעלות ואל תשנו פקודות קדימה — רק בלוק פנייה אחד מחליף כיוון.
    בדיקה: הקוד נשאר כמו שהיה, חוץ מפנייה אחת שהכיוון שלה השתנה.
  4. תרגול 4 — מחברים בלוק לקוד: סמנו על דף את כיוון הראש לפני כל פקודה.
    רמז: לחצו על בלוק וראו איזו שורת Python נדלקת בקוד.
    בדיקה: כאשר בוחרים בלוק, שורת Python המתאימה מודגשת.
  5. תרגול 5 — בדיקת מהנדסים: החליפו ימינה ושמאלה והשוו תוצאה.
    רמז: מהנדסים בודקים לפחות שני מצבים, לא רק הרצה אחת שעבדה במקרה.
    בדיקה: התלמיד/ה בדק/ה לפחות שתי הרצות והשווה/השוותה ביניהן.
  6. תרגול 6 — מסלול סגור קטן: בנו מסלול קטן שמסתיים בנקודת ההתחלה.
    רמז: נסו לבנות מסלול סגור: בסוף הצב צריך לחזור למקום שממנו התחיל.
    בדיקה: נקודת הסיום של הצב חוזרת לנקודת ההתחלה.

🧪 הרבה תרגולים לשיעור — 7–12

  1. תרגול 7 — שני צבעים במסלול: גרמו לצב לצייר מסלול אחד בשני צבעים שונים באותה הרצה.
    רמז: את בלוק הצבע מוצאים תחת ׳עט וצבע׳. אפשר להתחיל מהכחול ההתחלתי ואז לשנות לצבע נוסף באותה הרצה.
    בדיקה: הצב מצייר בשני צבעים שונים באותה הרצה.
  2. תרגול 8 — דיבאג מדרגות: תקנו את קוד המדרגות היורדות למטה: יש פנייה אחת לא נכונה שמקלקלת את המסלול.
    רמז: הקוד ההתחלתי אמור לבנות מדרגות יורדות. אל תשנו מרחקים ואל תמחקו בלוקים — מצאו את הפנייה שמקלקלת והחליפו רק את הכיוון שלה.
    בדיקה: מבנה המדרגות תקין: קדימה, ימינה, קדימה, שמאלה, קדימה — 3 פעמים.
  3. בדיקת איכות: בדקו שהתוכנית עובדת אחרי איפוס והרצה מחדש, לא רק פעם אחת.
    רמז: בדיקת איכות טובה מתחילה מאיפוס והרצה נקייה.
    בדיקה: התוכנית עובדת גם אחרי איפוס והרצה מחדש.
  4. הכנה להצגה: הכינו משפט הצגה: מה בניתי, באיזה בלוק השתמשתי, ואיפה רואים את זה בקוד.
    רמז: הצגה קצרה עדיפה על הסבר ארוך ומבולבל.
    בדיקה: יש משפט הצגה שמחבר תוצר, בלוק וקוד.
  5. רפלקציה קצרה: השלימו משפט: היום למדתי ש־___, ובפעם הבאה אשפר ___.
    רמז: רפלקציה קצרה עוזרת לזכור: מה ניסיתי, מה עבד, ומה תיקנתי?
    בדיקה: יש משפט סיכום אישי ומדויק.
  6. תרגול 9 — מדרגות בשני צבעים: חזרו למדרגות תקינות. הוסיפו צבע אחד לחלק הראשון של המדרגות, וצבע אחר לחלק השני. המדרגות עדיין צריכות להישאר מסודרות ונכונות.
    רמז: שימו בלוק צבע לפני המדרגה הראשונה, ואז בלוק צבע נוסף לפני אחת המדרגות הבאות. אל תשנו את הפניות או המרחקים.
    בדיקה: יש רצף מדרגות תקין, והצב מצייר בפועל לפחות בשני צבעים שונים.

🧪 הרבה תרגולים לשיעור — 13–13

  1. אתגר סיום — כותבים Python קצר: כתבו בתוך התיבה בלומדה 3 שורות Python קצרות שמתארות מדרגה אחת, למשל forward(50), right(90), forward(50).
    רמז: שימו את הבלוקים הרצויים באזור העבודה. בצד המסך יופיע קוד ה־Python שלהם — העתיקו ממנו 3 שורות קצרות לתיבה, ואז לחצו ״הרץ את הקוד שכתבתי״.
    בדיקה: יש בתיבה 3 שורות Python קצרות שיוצרות מדרגה קצרה ואפשר להריץ כמו בלוקים.

  • לתלמידים מתקדמים לתת וריאציה פתוחה, לא עוד פתרון מוכן.

עיקרון מוביל: לא מראים פתרון מלא. בונים ביטחון דרך ניסוי, הרצה, ניבוי ותיקון.

🛠️ טעויות נפוצות ודיבאג

  • מנסים לגרור הרבה בלוקים לפני הרצה ראשונה ואז קשה לדעת מה השפיע.
  • בונים ציור שנראה כמו מדרגות, אבל הבדיקה מצפה למבנה אחד מדויק מדי במקום לבדוק את הרצף עצמו.
  • משנים כמה דברים יחד ואז לא יודעים מה גרם לשינוי.
  • לא שמים לב שהשורה המודגשת בקוד היא חלק מהלמידה, לא קישוט.
  • בודקים רק מצב אחד ולכן חושבים שהפתרון תמיד עובד.
  • מוחקים את כל הפתרון במקום לתקן בלוק/ערך קטן.
  • מוסיפים קישוטים אבל מאבדים את מטרת השיעור.
  • אומרים “זה עובד” בלי להסביר למה.
  • לא מאפסים לפני בדיקה ולכן תוצאה ישנה מבלבלת.
  • מציגים רק את הציור ולא מסבירים את הקשר לבלוקים ולקוד.
  • מסיימים בלי לנסח מה למדו ומה ירצו לשפר.
  • מוסיפים צבעים אבל שוברים את סדר הפקודות של המדרגות.
  • מעתיקים קוד ארוך מדי בלי להבין מה כל שורה עושה.
לא מתקנים לילדים בידיים. שואלים: איפה הצב סטה? איזה בלוק/שורה אחראים לזה?
