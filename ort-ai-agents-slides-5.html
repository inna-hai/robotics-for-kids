למה סדר חשוב?

הוראות הן ספר הרכבה

בלי סדר

חלקים מפוזרים, קשה להבין מה עושים קודם ומה חשוב.

עם סדר

כותרות, שלבים, כללים ודוגמאות. קל יותר לבנות ולבדוק.

להציג לתלמידים את ההבדל בין פסקה מבולגנת למסמך עם כותרות.
Markdown

לא להעמיס תחביר. מספיק #, ## ורשימות.

JSON

מידע במגירות

אנלוגיה

JSON הוא כמו ארון מגירות: לכל דבר יש שם ומקום קבוע.

למה זה עוזר?

שם, קהל יעד, מטרה, יכולות וגבולות נמצאים במבנה ברור.

להרגיע: זה לא שיעור תכנות. רק מבנה מידע.
תבנית JSON

מבנה בסיסי

{ "name": "שם הסוכן", "audience": "למי הוא מיועד", "goal": "מה המטרה שלו", "capabilities": ["יכולת 1", "יכולת 2"], "boundaries": ["גבול 1", "גבול 2"] }

זה לא מבחן תכנות. זו דרך לארגן מידע.

אפשר להצביע על מירכאות, פסיקים ורשימות, בלי להעמיק מעבר.
