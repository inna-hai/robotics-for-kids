זה לא פרויקט סיום. זה שיעור מעבר שמלמד איך עובדים כמו מפתחים: לא מוחקים הכול — מתקנים נקודתית.

🧭 מבנה 90 דקות

  1. 0–8 פתיחה: מה זה באג בציור?
  2. 8–18 מריצים כרטיס כמעט מוכן ומזהים בעיות.
  3. 18–36 מתקנים מסגרת ומעבר עם penup/pendown.
  4. 36–55 מסדרים צבעים ומוסיפים קישוט בלולאה.
  5. 55–70 בדיקת איכות ושדרוג אישי קטן.
  6. 70–82 בדיקה בזוגות: אחד מריץ ואחד מסביר.
  7. 82–90 הצגה קצרה: באג → תיקון → שדרוג.

👩‍💻 עבודה בשורות קוד

כמו בשיעור 12: גוררים פקודה והיא הופכת לשורת Python. מתקנים מספרים וצבעים בתוך השורה.

color("purple") repeat 4: forward(120) right(90) penup() forward(80) pendown()
בלולאה: גוררים את מספר השורה מתחת לשורת repeat כדי להכניס אותה פנימה.

🧪 הרבה תרגולים לשיעור — 1–4

  1. מתקנים את הבאגים הראשונים
    מסגרת שלא נסגרת וקו מעבר מיותר.
  2. מדגישים את המסגרת
    מוסיפים width למסגרת אחרי שהיא נסגרת.
  3. מסדרים צבעים
    לפחות שלושה צבעים: מסגרת, קישוט ופרט נוסף.
  4. קישוט ראשון חדש בלולאה
    מוסיפים repeat נוסף מעבר למסגרת ולקישוט ההתחלתי.

🧪 הרבה תרגולים לשיעור — 5–9

  1. סימן חתימה מצויר
    עוברים למטה בלי קו מיותר ומציירים סימן קטן עם forward ופנייה.
  2. קישוט שני במקום אחר
    עוברים עם penup/pendown ומוסיפים repeat נוסף.
  3. בדיקת איכות
    מסגרת, מעברים נקיים, 3 צבעים, width וקישוט בלולאה.
  4. בנק שדרוגים
    צבע רביעי, קישוט נוסף, מעבר נוסף או עובי מיוחד.
  5. מציגים את התיקון
    “הבאג היה ___, תיקנתי בעזרת ___, והשדרוג שלי הוא ___.”

👩‍🏫 דגשי מדריך

  • לא לתת פתרון מלא — לבקש מהילדים להצביע על שורת הקוד החשודה.
  • אחרי כל שינוי מריצים שוב, כדי לדעת מה השפיע.
  • להזכיר ש־color משפיע על מה שמצויר אחריו.
  • להדגים מעבר נקי עם penup ואז pendown.
  • לתלמידים מהירים: שדרוג קטן נוסף, לא ציור חדש מאפס.
השפה של השיעור: באג → שורה חשודה → תיקון קטן → הרצה מחדש.

✅ איך יודעים שהצליח?

  • הכרטיס מצויר עם מסגרת מסודרת.
  • אין קווי מעבר מיותרים.
  • יש לפחות שלושה צבעים בזמן נכון.
  • יש לפחות שני קישוטים/לולאות מעבר למסגרת.
  • התלמיד/ה מסביר/ה באג אחד ושורת קוד שתיקנה אותו.

🛠️ טעויות נפוצות

  • מוחקים הכול במקום לתקן שורה אחת.
  • שמים color אחרי הציור ואז מתפלאים שהצבע לא השתנה.
  • זזים למקום חדש בלי penup ומשאירים קו מיותר.
  • מוסיפים הרבה קישוטים ומאבדים את הכרטיס המקורי.
  • לא מריצים מהתחלה אחרי תיקון.
