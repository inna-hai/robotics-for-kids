  2. 8–18 — הדגמה קצרה בלי פתרון מלא
    מדגימים רק התחלה: בלוק אחד או שניים שמראים דפוס חוזר. לא חושפים את כל הפתרון.
  3. 18–34 — בנייה מודרכת
    מובילים את תרגילים 1–5 בקצב כיתה, עם עצירות ניבוי קצרות.
  4. 34–48 — בלוק → Python
    מחברים בין הבלוקים לשורות הקוד. מדגישים את הגשר: בלוק → שורת קוד מודגשת.
  5. 48–64 — תרגול עצמאי
    נותנים לתלמידים לעבוד על תרגילים 6–10 בלי להראות פתרון מלא.
  6. 64–76 — דיבאג ושיפור
    נותנים באג נפוץ אחד ושואלים איך מאתרים אותו בלי למחוק הכל.
  7. 76–84 — אתגר יצירתי קצר
    פותחים בחירה אישית מוגבלת כדי לשמור על הצלחה: צבע, גודל, דפוס או פרט אישי.
  8. 84–90 — שיתוף וסיכום
    מבקשים 2–3 הצגות קצרות ומסכמים במבנה: רעיון → בלוקים → קוד → ציור.

🧪 הרבה תרגולים לשיעור — 1–5

  1. תרגול 1 — קרש ראשון בגדר: ציירו קרש גדר קטן: קו למעלה, קו קצר הצידה, וקו למטה. בחרו צבע לקרש.
    בדיקה קצרה: יש קרש גדר קטן עם קו למעלה, קו קצר הצידה וקו למטה,…
  2. תרגול 2 — שורת גדר קצרה: עטפו את קרש הגדר בבלוק ״חזור״ 4 פעמים.
    בדיקה קצרה: קרש הגדר חוזר 4 פעמים, ובכל חזרה יש גם קו קטן…
  3. תרגול 3 — שורת גדר ארוכה: שנו את מספר החזרות ל־8 כדי ליצור שורת גדר ארוכה יותר, עם קו קטן בין כל שני קרשים.
    בדיקה קצרה: אותו קרש גדר חוזר 8 פעמים, כולל הקו הקטן שמפריד בין…
  4. אתגר קטן — מתחילים משמאל: לפני שורת הגדר הארוכה, הזיזו את הצב שמאלה בלי לצייר.
    בדיקה קצרה: הצב זז שמאלה בלי לצייר לפני תחילת הגדר, ואז מצייר…
  5. תרגול 4 — קרש דו־צבעי חוזר: שדרגו את הגדר: בתוך בלוק ״חזור״ ציירו בכל פעם קרש גדר אחד, אבל הקרש עצמו צריך להיות…
    בדיקה קצרה: בכל חזרה יש קרש גדר עם שני צבעים, ויש קו קטן שמוביל…

🧪 הרבה תרגולים לשיעור — 6–10

  1. תרגול 5 — מתקנים קרש שבור בלולאה: קיבלתם גדר כמעט מוכנה.
    בדיקה קצרה: בתוך הלולאה יש קרש גדר שלם וקו קטן שמוביל לקרש הבא.
  2. תרגול 6 — תקנו בלוק מיותר: תקנו את הקוד: הסירו את הבלוק שמקלקל את הדפוס החוזר.
    בדיקה קצרה: הדפוס החוזר נשאר מסודר אחרי שמסירים את הבלוק המיותר.
  3. תרגול 7 — מסגרת מחברת: בנו מסגרת מחברת בעזרת דפוס חוזר שסוגר צורה מסביב לדף.
    בדיקה קצרה: הדפוס החוזר סוגר מסגרת או צורה שחוזרת לנקודת ההתחלה.
  4. אתגר רשות — גדר עם שפיצים: שדרגו את הגדר: בנו קרש גדר עם שפיץ קטן למעלה, כמו בגדרות מצוירות.
    בדיקה קצרה: אין בדיקה אוטומטית לאתגר — הריצו ובדקו שיש שורת גדר…
  5. אתגר מסכם — כותבים Python קצר: כתבו בקוד Python את שורת הגדר שבניתם בבלוקים: השתמשו ב־for כדי לחזור כמה פעמים, ובכל…
    בדיקה קצרה: יש לולאת for, ובתוכה קרש גדר בסיסי עם קו קטן שמוביל…
